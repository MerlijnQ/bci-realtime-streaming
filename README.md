# bci-realtime-streaming
First, run streamer.py in a terminal. You should use python3 -m src.streamer
Then, run the other files in another terminal. For instance, python3 -m examples.visualize_eeg_live_plotter

We have tried multiple ways of plotting the data: for the fast plotting, run visualize_eeg_fast_plotter.py, for the live_plotting with a sliding window, rung visualize_eeg_live_plotter.py
